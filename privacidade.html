Aviso de privacidade

Versão para apresentação — atualizada em 3 de agosto de 2026.

Estado atual: o cadastro está em modo de demonstração. Os dados preenchidos no formulário não são enviados nem armazenados. Este aviso explica como o recurso será ativado de forma responsável.

Quais dados serão solicitados

Nome de preferência, e-mail, faixa etária, etapa escolar e, se a pessoa quiser, estado e cidade. Esses dados servem para criar um perfil, personalizar orientações de curso e permitir o acesso ao próprio espaço no Orion.

O que não pedimos

Não pedimos CPF, endereço, documentos, renda, senha, foto, dados de saúde ou notas do Enem como condição para criar o perfil.

Métricas de acesso

Usamos o Google Analytics para entender, de forma agregada, quantas pessoas acessam o site e quais páginas são mais visitadas. Essa ferramenta pode registrar informações técnicas como dispositivo, navegador e localização aproximada. Não enviamos nomes, e-mails, notas ou informações do cadastro para o Google Analytics.

Como a conta funcionará

O acesso será feito por e-mail verificado. Os dados ficarão em banco protegido, com regras para que cada estudante veja e altere apenas o próprio perfil. O Orion não venderá nem divulgará os dados para publicidade.

Crianças e adolescentes

O Orion é voltado principalmente a estudantes. Para menores de 13 anos, o cadastro real só será ativado com autorização de responsável. Para adolescentes, a coleta buscará sempre o melhor interesse, com linguagem clara e o mínimo de informações necessário.

Seus direitos e contato

Você poderá pedir acesso, correção ou exclusão de seus dados. Para isso, envie um e-mail para projeto.aquiless@gmail.com. Se o projeto mudar o modo como usa os dados, este aviso será atualizado antes da mudança entrar em vigor.
